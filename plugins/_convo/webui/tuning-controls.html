Decision backends
Manual decision registration override

Requires System One enabled, its Convo consumer opted in, and a provisioned compatible backend. No model is downloaded or loaded here; no automatic classifier fallback. Main, Utility and Embedding routes are unchanged.

The classifier itself (provider, model, address, key, or System One’s decider) is set in Settings → Connections → Classifier; this picker is for a backend another provisioner registered.

Speech gate: when to answer, interrupt or stay quiet

With a System One decision backend, Convo answers from the classifier's probabilities instead of a fixed confidence cut-off. Every value is a probability from 0 to 1. The defaults were measured for one decision model on synthetic speech; measure them again for another model or for real voices (tests/calibrate_gate.py). A classifier that returns only a self-reported confidence cannot be calibrated: it keeps fixed thresholds and the readiness list says it is unsupported. Work with side effects always needs an explicit request at 0.9 or more, whatever is set here.

Turn engine: speed and recovery (experimental)

These change how a reply is produced, not what is allowed. Safety rules (who may speak, tools needing an explicit request, the two-second stop) are unchanged. Nothing here is measured on real voices yet.

Faster, but every completed utterance in active listening also goes to the conversation model, even speech the classifier would then ignore. Nothing is shown, spoken or run unless the turn is admitted. Never used in ambient or name listening.

The model may answer exactly [LISTEN]. That only suppresses a reply; it can never make Convo answer something the classifier declined.

Joining keeps the audio of an unfinished or still-unanswered utterance in memory only (never saved) so the next fragment is answered with it. Remembered remarks keep recently ignored speech in memory for that long and send it to the conversation model only with a later admitted turn, labelled as overheard.
