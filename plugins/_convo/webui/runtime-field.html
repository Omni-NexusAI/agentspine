Convo runtime

Run Convo’s own runtime (recommended)
The service that calls your models during a conversation. On: Convo starts it with Agent Zero whenever Convo is on, and a voice session starts it if it has stopped; nothing to install. Off: Convo uses a gateway you run yourself (advanced).

Speech output uses audio.cpp managed by Convo, which runs inside Convo’s own runtime: turn it on above, or choose another speech connection.
