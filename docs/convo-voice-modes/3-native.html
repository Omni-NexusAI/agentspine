What to look at

  • Hidden means folded, never deleted. A card the mode does not use becomes one dashed line: what it is set to, why it is not used, and a button to open it anyway. Saved values stay and come back with Hybrid.
  • “Approves delegated work only” is a limited role, shown with a dotted tag, not a hidden card. Work with side effects keeps the same rule in every mode: an explicit request at 0.9 or more.
  • The privacy difference is stated up front. Hybrid sends finished sentences. Native sends everything while the microphone is open. The note says so before anyone starts.
  • A setting a mode fixes is shown locked, with the reason (Accepts audio input: “Always on in Native mode”).
  • Other places: Voice & Audio → Echo protection warns that Strict stops you interrupting the model. Diagnostics → Tune shows “Applies in Hybrid only” above the speech gate and turn engine; their values stay editable.
