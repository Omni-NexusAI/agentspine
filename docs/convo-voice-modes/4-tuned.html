4 · Tuned chosen (after build step 7), with one thing still missing

A fine-tuned conversation model takes turns by itself inside a harness made for it. Tuned needs three things: a harness for this model, live speech input, and a speech output. One is missing here, so the mode card lists what to do.

What to look at

  • “Needs setup (1)” instead of a refusal. A mode that is built but not ready can still be chosen. The card lists what it needs, each item with icon and words and a link to the card that fixes it. Start refuses with the same words until it is fixed.
  • Required is a solid tag, limited is dotted, not used is dashed, always with words, so the tags read the same without colour.
  • New card only where needed. Speech input appears in Connections only in Tuned mode; nothing about it shows in Hybrid or Native.
  • Floors per model. Decision floors belong to one model and must be measured again after each fine-tune; the row says when and how they were measured.
