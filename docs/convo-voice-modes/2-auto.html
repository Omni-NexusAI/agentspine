2 · Auto: what it picked, why, and how to override it

While Auto is chosen, its answer is always on screen: the mode it picked, one sentence of why, and the full reasoning one click away. Overriding is one button that switches to the mode Auto picked, or any radio.

What to look at

  • The answer is never hidden. With Auto chosen, the picked mode is in the Auto option’s badge and in a status box, and “Who does what” describes the picked mode.
  • Reasoning as five numbered steps, the one that decided in bold and marked “Used”. The steps are the same every time, so a person learns to read them once.
  • Override in one click. “Always use Hybrid” selects the Hybrid radio (an ordinary change, saved with Save). Choosing any radio is also an override.
  • No silent change (B). When Auto’s pick for the same model differs from last time, the card says so with the reason and Convo refuses to start until the person chooses. The panel shows the same refusal (page 5, C).
  • Learning only by a click. “Keep Hybrid for this model” is how Convo remembers a per-model choice; nothing is learned silently from use.
